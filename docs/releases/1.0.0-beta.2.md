# Abigent 1.0.0 Beta 2

这是 Abigent 的 macOS 14 启动兼容性修复版本。

## 下载

- `Abigent-1.0.0-beta.2-macOS-arm64.dmg`
- `Abigent-1.0.0-beta.2-macOS-arm64.dmg.sha256`

## 本次修复

- 修复 macOS 14 启动时可能触发 AttributeGraph fatal error、点击“打开”后无响应的问题。
- 桌面小猫与 Codex 连接改为在 SwiftUI 根界面完成挂载后启动。
- 启动入口增加幂等保护，避免重复创建窗口或监听服务。

## 系统要求

- Apple Silicon Mac（M1 或更新）
- macOS 14.0 或更新
- Codex 桌面应用

## 首次打开

这是免费个人分享版，使用临时签名，没有 Apple Developer ID 和公证。

1. 将 Abigent 拖入“应用程序”。
2. 尝试打开一次。
3. 前往“系统设置 → 隐私与安全性”。
4. 点击 Abigent 旁的“仍要打开”，然后再次确认“打开”。
5. 启用实时同步，并使用 `⌘Q` 完整重启 Codex。

如果安装过 Beta 1，请完全退出 Abigent 后将 Beta 2 拖入“应用程序”并选择“替换”。任务记录、小猫位置和 Hook 配置会保留。

## 已知限制

- 未公证，首次打开必须由用户手动允许。
- 仅支持 Apple Silicon 与 macOS 14+。
- V1 正式支持 Codex；Trae CN 尚未接入。
- 完整 XCTest 需要安装完整 Xcode。

shasum -a 256 -c Abigent-1.0.0-beta.2-macOS-arm64.dmg.sha256
