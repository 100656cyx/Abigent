# Abigent 1.0.0 Beta 4

这是 Abigent 的 Codex 延迟写盘与同会话多轮结果恢复修复版本。

## 下载

- `Abigent-1.0.0-beta.4-macOS-arm64.dmg`
- `Abigent-1.0.0-beta.4-macOS-arm64.dmg.sha256`

## 本次修复

- 结果恢复按“会话 ID＋Stop 时间”独立管理；同一会话的新一轮不会取消上一轮恢复。
- Codex 最终回复尚未写入本地会话文件时，Abigent 会在约十分钟的有界窗口内持续检查。
- 所有重试始终使用原 Stop 时间选择任务轮次，避免读到下一轮回复。
- 同一轮来自 Hook 与状态恢复的重复请求会自动去重。

## 系统要求

- Apple Silicon Mac（M1 或更新）
- macOS 14.0 或更新
- Codex 桌面应用

## 首次打开与升级

这是免费个人分享版，使用临时签名，没有 Apple Developer ID 和公证。

1. 完全退出旧版 Abigent。
2. 将新版从 DMG 拖入“应用程序”，选择“替换”。
3. 如果 macOS 阻止首次打开，请前往“系统设置 → 隐私与安全性”，点击“仍要打开”。
4. 使用 `⌘Q` 完全退出并重新打开 Codex，然后发送一个新任务。

升级会保留任务记录、小猫位置和 Hook 配置。

## 校验

```bash
shasum -a 256 -c Abigent-1.0.0-beta.4-macOS-arm64.dmg.sha256
```
