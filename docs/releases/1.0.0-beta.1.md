# Abigent 1.0.0 Beta 1

第一个可分享的 Abigent Beta：一只完全在本地运行的 Codex 桌面小猫。

## 下载

- `Abigent-1.0.0-beta.1-macOS-arm64.dmg`
- `Abigent-1.0.0-beta.1-macOS-arm64.dmg.sha256`

## 系统要求

- Apple Silicon Mac（M1 或更新）
- macOS 14.0 或更新
- Codex 桌面应用

## 主要能力

- 实时跟踪 Codex 工作中、需要操作和任务完成状态。
- 悬停小猫查看本轮回复摘要、返回时间、修改文件和测试结果。
- 小猫窗口、摘要浮层和操作框相互独立，悬停不会移动小猫位置。
- 支持拖动、50%–150% 缩放和位置/大小保存。
- 双指点按或鼠标右键打开操作框。
- 仅在需要操作和任务完成时通知。
- 与已有 Codex Hooks 共存。
- 全部内容在本机处理，不需要 Abigent 账号。

## 首次打开

这是免费个人分享版，使用临时签名，没有 Apple Developer ID 和公证。

1. 将 Abigent 拖入“应用程序”。
2. 尝试打开一次。
3. 前往“系统设置 → 隐私与安全性”。
4. 点击 Abigent 旁的“仍要打开”。
5. 启用实时同步，并使用 `⌘Q` 完整重启 Codex。

DMG 内附带《首次打开说明》，仓库中也提供 [INSTALL.md](../../INSTALL.md)。

## 已知限制

- 未公证，首次打开必须手动允许。
- 仅支持 Apple Silicon 与 macOS 14+。
- V1 正式支持 Codex；Trae CN 尚未接入。
- 完整 XCTest 需要安装完整 Xcode。

## 校验

shasum -a 256 -c Abigent-1.0.0-beta.1-macOS-arm64.dmg.sha256
