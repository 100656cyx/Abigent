# Abigent 1.0.0 Beta 3

这是 Abigent 的 Codex 同一会话连续任务摘要同步修复版本。

## 下载

- `Abigent-1.0.0-beta.3-macOS-arm64.dmg`
- `Abigent-1.0.0-beta.3-macOS-arm64.dmg.sha256`

## 本次修复

- 修复同一 Codex 会话快速开始下一轮时，上一轮结果可能一直显示“任务已完成，结果同步中”的问题。
- 结果提取改为使用 Hook Stop 时间锁定对应任务轮次；恢复重试期间出现的新一轮不会再改变目标。
- 保留对缺少事件时间戳的旧会话记录兼容。
- 增加“上一轮完成后立即开始下一轮”的回归测试。

## 系统要求

- Apple Silicon Mac（M1 或更新）
- macOS 14.0 或更新
- Codex 桌面应用

## 首次打开与升级

这是免费个人分享版，使用临时签名，没有 Apple Developer ID 和公证。

1. 完全退出旧版 Abigent。
2. 将新版 Abigent 从 DMG 拖入“应用程序”，选择“替换”。
3. 如果 macOS 阻止首次打开，请前往“系统设置 → 隐私与安全性”，点击“仍要打开”。
4. 使用 `⌘Q` 完全退出并重新打开 Codex，然后发送一个新任务。

升级会保留任务记录、小猫位置和 Hook 配置。

## 已知限制

- 未公证，首次打开必须由用户手动允许。
- 仅支持 Apple Silicon 与 macOS 14+。
- V1 正式支持 Codex；Trae CN 尚未接入。

shasum -a 256 -c Abigent-1.0.0-beta.3-macOS-arm64.dmg.sha256
