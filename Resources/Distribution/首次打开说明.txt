Abigent 1.0.0 Beta — 首次打开说明
===================================

Abigent 是一个完全在本机运行的 Codex 桌面伴侣。
这个免费个人分享版使用临时签名，没有购买 Apple Developer ID，也没有经过 Apple 公证。
因此 macOS 第一次打开时会要求你手动确认一次。

系统要求
--------
- Apple Silicon Mac（M1 或更新）
- macOS 14.0 或更新
- 已安装 Codex 桌面应用

安装
----
1. 将“Abigent”拖到旁边的“Applications”文件夹。
2. 打开“应用程序”，双击 Abigent。
3. 如果 macOS 提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”，先关闭提示。
4. 打开“系统设置 → 隐私与安全性”。
5. 向下滚动到安全性区域，在 Abigent 的提示旁点击“仍要打开”。
6. 在再次出现的确认框中点击“打开”。这个确认通常只需要一次。

连接 Codex
----------
1. 在 Abigent 首次设置中点击“启用实时同步”。
2. 使用 Command-Q 完全退出 Codex；只关闭窗口不会重新加载配置。
3. 重新打开 Codex，并进入任意会话发送一个任务。
4. 小猫应显示工作状态；任务完成后，鼠标悬停小猫可查看本轮摘要。

基本操作
--------
- 移动：按住小猫主体并拖动。
- 操作框：触控板双指点按，或使用鼠标右键。
- 缩放：在操作框中使用 50%–150% 大小滑块。
- 摘要：悬停小猫查看，摘要使用独立浮层，不会移动小猫位置。

升级
----
1. 完全退出旧版 Abigent。
2. 将新版 Abigent 拖入“应用程序”，选择替换。
3. 如果 macOS 再次提示安全确认，重复“隐私与安全性 → 仍要打开”。

卸载
----
1. 在 Abigent 设置中点击“停用 Abigent Hook”。
2. 退出 Abigent，并从“应用程序”删除它。
3. 可选删除本地数据：
   ~/Library/Application Support/Abigent/
   ~/.abigent/

安全说明
--------
- 不要关闭 Gatekeeper，也不要执行来源不明的终端命令来绕过系统安全检查。
- 只从项目 GitHub Release 或你信任的分享者获取安装包。
- 可使用同目录提供的 SHA-256 文件验证 DMG 是否完整。
- Abigent 不需要账号；任务状态和摘要都在本机处理。
