# Abigent pet asset

`abigent-base.png` is the approved half-realistic character generated from the user-supplied cat reference. It preserves the cat's tall ears, golden eyes, narrow face, warm taupe short coat, slim build, and long tail. The checked-in image has an alpha channel and no background.

The app uses this base illustration with native transforms and semantic badges for idle, working, needs-input, completed, and disconnected states. This keeps the first release small while leaving room for hand-authored frame animation in a later art pass.
